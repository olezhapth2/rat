## Обзор проекта

**SECRET GANG** — браузерная 2D RPG в стиле pixel art. Игроки перемещаются по офису, общаются, оформляют кабинет мебелью, играют в мини-игры и соревнуются в лидербордах.

Ключевые особенности:
- Реалтаймовый мультиплеер через WebSocket
- Кастомизация офиса: 66 предметов мебели (столы, стулья, диваны, освещение, декор, мини-игры)
- 6 мини-игр с серверными лидербордами
- Система монет, опыта и уровней
- Ежедневные квесты
- Панель администратора для управления игроками и достижениями
- Retro FX: CRT-эффекты, сканлайны, шум, цветовые фильтры, виньетирование

## Как запустить

```bash
# Установка зависимостей
npm install

# Разработка (сервер на порту 3001)
npm run dev

# Билд + продакшн
npm run build
npm start
```

Для подключения мультиплеера нужен переменная окружения:
```
NEXT_PUBLIC_SERVER_URL=http://localhost:3001
```

## Фронтенд

### Структура

| Файл | Описание |
|------|----------|
| `src/components/GameCanvas.tsx` | Основной компонент игры (~3400 строк). Включает: рендеринг Canvas, управление, UI, все оверлеи |
| `src/components/AdminPanel.tsx` | Админ-панель: управление пользователями, игроками, достижениями, деньгами |
| `src/components/RetroPanel.tsx` | Панель Retro FX: выбор CRT, сканлайнов, шума, цвета, виньетки |
| `src/components/RetroEffects.tsx` | CSS-эффекты: VHS-полосы, покачивание, цветовой дрейф |
| `src/app/globals.css` | Win95-тема, стили панелей, кнопок, эмодзи-бар |

### Рендеринг (renderer.ts)

Всё рисуется на HTML5 Canvas 2D. Порядок отрисовки:
1. Пол (тайлы 5 вариантов)
2. Боковые стены (S-тайлы, 3 ряда)
3. Стены (W-тайлы)
4. Объекты и персонажи (сортировка по глубине Y)
5. Несущие предметы (над головой)
6. Превью размещения мебели
7. Превью покраски тайлов
8. Речевые пузыри и эмодзи

### Ввод (input.ts)

- WASD / стрелки — движение
- Клик по карте — автопереход
- Колёсико мыши — зум
- ПКМ — контекстное меню

### Спрайты (sprites.ts)

6 персонажей: `pers1` (Олег), `pers2` (Анна), `pers3` (Алиса), `pers4` (Кирилл), `pers5` (Саша), `kryska` (Крыска).

Каждый спрайт — 212×424 px (1:2), кропается до 1:1 для аватарок в HUD и профиле через `object-fit: cover`.

Анимация: idle/run, 4 направления (front/back/left/right).

## Бэкенд

### Сервер (server.ts)

Кастомный HTTP-сервер поверх Next.js с Socket.IO. Порт: 3001.

**Socket-события (~50 обработчиков):**

| Категория | События |
|-----------|---------|
| Игрок | `player:register`, `player:move`, `player:save` |
| Тайлы | `tile:paint`, `tile:remove`, `tile:reset` |
| Мебель | `item:place`, `item:remove` |
| Whiteboard | `whiteboard:update`, `whiteboard:request_sync` |
| КНБ | `rps:invite`, `rps:accept`, `rps:decline`, `rps:choice`, `rps:cancel` |
| Эмодзи | `emoji:send` |
| Карточная игра | `cardgame:create`, `cardgame:join`, `cardgame:play`, `cardgame:draw`, `cardgame:leave` |
| Авторизация | `auth:login`, `auth:reconnect`, `auth:first-login`, `auth:create-user`, `auth:update-user`, `auth:delete-user` |
| Админ | `admin:get-players`, `admin:add-player`, `admin:delete-player`, `admin:adjust-money`, `admin:get-achievements`, `admin:create-achievement`, `admin:grant-achievement` |
| Лидерборды | `leaderboard:submit`, `leaderboard:sync`, `leaderboard:updated` |

### Авторизация

- Регистрация только через админ-панель
- Логин по email + пароль
- Сессия сохраняется в localStorage
- При перезагрузке страницы — автопереподключение

## Хранение данных

Все данные хранятся в `.game-data/` (JSON-файлы):

| Файл | Назначение |
|------|-----------|
| `players.json` | Данные игроков: монеты, мебель, достижения, размещённые предметы |

| `game-state.json` | Общее состояние: замена тайлов, общие предметы, whiteboard |
| `leaderboards.json` | Лидерборды по 6 играм (top 20 каждая) |
| `custom-achievements.json` | Пользовательские достижения (создаются админом) |
| `custom-sprites/` | Загруженные пользовательские спрайты |

> **Важно:** Данные хранятся на диске VPS в `.game-data/`. При деплее через `git pull` данные сохраняются.

## Мини-игры

### 🚬 Сигаретная (Smoking)
- Нужно нажать 30 раз за 20 секунд
- Награда: 20 монет + 15 XP
- Лидерборд: быстрее = лучше

### ⏱️ Подогрей обед (Microwave)
- Остановить таймер ровно на 5.000 секундах
- Чем ближе к 5.000 — тем больше награда (до 35 монет)
- Лидерборд: лучшая награда

### 🏀 Баскетбол (Basketball)
- 10 попыток забросить мяч в кольцо (свайпом)
- 15 монет за каждый заброшенный
- Лидерборд: максимум из 10

### ✊ Камень-Ножницы-Бумага (RPS)
- PvP: приглашение другому игроку через контекстное меню
- Победа: +20 монет, Ничья: +5 монет
- Серверная логика, синхронизация в реальном времени
- Лидерборд: общее количество монет

### 🃏 ОКИЯ (Card Game / UNO-style)
- 108 карт: 4 цвета, числа 0-9, skip, reverse, +2, wild, wild+4
- 2-4 игрока, автостарт при 2+ участниках
- Полная логика UNO
- Лидерборд: победы

### 🪑 Мебельный тoss (Furniture Toss)
- 8 попыток кидать мебель в цель
- 10 монет за каждый попадание
- Лидерборд: максимум из 8

### 📖 Прогноз дня (Book Prediction)
- 20 случайных шуточных предсказаний
- Без награды, просто развлечение

## Мультиплеер

- Реалтайм через Socket.IO (WebSocket + polling fallback)
- Позиции игроков синхронизируются в реальном времени
- Общая мебель (placement sync)
- Покраска тайлов (tile sync)
- Whiteboard (совместный рисунок)
- КНБ и карточная игра — полноценные PvP
- Эмодзи-чат (8 эмодзи, показываются над персонажем)
- Список онлайн-игроков в HUD

## Система лидербордов

Серверная система. Каждый игрок видит рекорды всех игроков.

| Игра | Метрика | Сортировка |
|------|---------|------------|
| 🚬 Сигаретная | Время (мс) | Меньше = лучше |
| ⏱️ Подогрей обед | Награда (монеты) | Больше = лучше |
| 🏀 Баскетбол | Забито из 10 | Больше = лучше |
| ✊ КНБ | Заработано монет | Больше = лучше |
| 🃏 ОКИЯ | Победы | Больше = лучше |
| 🪑 Мебельный toss | Попадания из 8 | Больше = лучше |

- Top 20 на сервере, top 5 в UI
- Медали для топ-3 (🥇🥈🥉)
- Синхронизация в реальном времени
- Кнопка `🏆 SCORES` в HUD

## Админ-панель

Доступна для пользователей с флагом `admin`.

4 вкладки:
- **Users** — создание/удаление/редактирование аккаунтов (email, имя, пароль, роль, аватар, права admin)
- **Players** — создание/удаление игровых профилей, корректировка монет
- **Money** — быстрая корректировка монет для любого игрока
- **Achievements** — создание кастомных достижений, выдача игрокам

---

## Retro FX

Админ-панель с 5 группами эффектов:

| Группа | Эффекты |
|--------|---------|
| CRT | Barrel distortion (2 уровня), Curvature (2), Glow (2) |
| Scanlines | CRT (2), RGB (2), Horizontal line (2) |
| Noise | Grain (2), VHS (2), TV static (2) |
| Color | Warm, Cool, Vivid, Retro, GameBoy, Amber |
| Vignette | Dark (2), Corner (2), Tunnel (2) |

Эффекты применяются через CSS: `perspective`, `rotateX`, `box-shadow`, `filter`, анимации.

## Вынос данных с локала

### Что сейчас захардкожено

| Файл | Что внутри | Выносим в |
|------|-----------|-----------|
| `constants.ts` | Карта, предметы магазина, боты | JSON на сервере |
| `interactions.ts` | Зоны взаимодействий | JSON на сервере |
| `okiya.ts` | Правила ОКИЯ | JSON на сервере |
| `cardgame.ts` | Правила UNO | JSON на сервере |

### Целевая структура

```
server/
├── game-config/
│   ├── map.json            ← карта (58×45 тайлов)
│   ├── shop.json           ← предметы магазина
│   ├── bots.json           ← боты (позиции, диалоги)
│   ├── interactions.json   ← зоны взаимодействий
│   ├── items.json          ← спрайты предметов
│   └── config.json         ← общие настройки
├── game-data/              ← пользователи, лидерборды
├── server.ts
└── public/sprites/
```

### API для загрузки данных

```typescript
// Сервер отдаёт данные
app.get('/api/map', (req, res) => {
  const map = JSON.parse(readFileSync('game-config/map.json', 'utf-8'));
  res.json(map);
});

app.get('/api/shop', (req, res) => {
  const shop = JSON.parse(readFileSync('game-config/shop.json', 'utf-8'));
  res.json(shop);
});

app.get('/api/bots', (req, res) => {
  const bots = JSON.parse(readFileSync('game-config/bots.json', 'utf-8'));
  res.json(bots);
});

app.get('/api/interactions', (req, res) => {
  const interactions = JSON.parse(readFileSync('game-config/interactions.json', 'utf-8'));
  res.json(interactions);
});
```

### Клиент загружает данные

```typescript
// При старте игры
const [map, shop, bots, interactions] = await Promise.all([
  fetch('/api/map').then(r => r.json()),
  fetch('/api/shop').then(r => r.json()),
  fetch('/api/bots').then(r => r.json()),
  fetch('/api/interactions').then(r => r.json()),
]);
```

### Что赢得аем

- ✅ Клиент может менять карту без разработчика
- ✅ Клиент может добавлять предметы в магазин
- ✅ Клиент может менять ботов и диалоги
- ✅ Всё хранится на VPS, не локально
- ✅ Обновления через админ-панель

### Приоритеты работ

1. **Docker + деплой** — создать Dockerfile, docker-compose.yml
2. **Вынос карты** — map.json на сервере
3. **Вынос магазина** — shop.json на сервере
4. **Вынос ботов** — bots.json на сервере
5. **Вынос взаимодействий** — interactions.json на сервере
6. **Админ-панель** — редактирование JSON через веб
